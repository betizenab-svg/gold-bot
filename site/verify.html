Check the record yourself

Every signal is written to a public file on GitHub the same run it is sent to Telegram, and every result is added the run it happens. Nothing is ever edited afterwards:

  1. Each record carries a fingerprint (SHA-256) of the record before it. Changing or deleting any old record breaks every fingerprint after it.
  2. GitHub keeps the full history of the file with dates. Anyone can see exactly when each line was added.
